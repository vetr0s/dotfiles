Verification boundaries

The macOS host cannot start the Linux systemd user service. Its unit, deployment path, and shell control flow passed static and isolated checks. AeroSpace was not running during the final pass, so its live semantic reload was unavailable. Its TOML parsed successfully. shellcheck and shfmt were not installed. Both supported Bash interpreters parsed every script.

The Emacs lock prevents an archive from installing an unreviewed revision. Package archives may remove old builds. The lock detects that state but cannot restore an artifact the archive no longer serves. This is a declared limit of the current built-in package.el design.
